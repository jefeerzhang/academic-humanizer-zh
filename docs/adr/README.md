# Architecture Decision Records (ADR)

This directory holds **recorded architecture decisions** for `academic-humanizer-zh`.

- New ADRs are added lazily when a design choice is actually resolved (see `docs/agents/domain.md`).
- Filename pattern: `NNNN-short-title.md` (e.g. `0001-layer7-compound-sections.md`).
- When an agent output contradicts an ADR, cite the ADR and explain why reopening is warranted.

There is no requirement to pre-populate ADRs; an empty directory is valid until the first decision is recorded.
