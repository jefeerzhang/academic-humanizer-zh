# Rules · 中文（学术写作）

> 路由：当 SKILL.md "Language routing and the C0–C7 contract" 的切换条件成立时进入本规则集（按可编辑散文的主导语言判断，不看字符占比——路由逻辑以 SKILL.md 为准）。
>
> 本文件只覆盖**本地风格修复（C7）**。锁定 span、术语一致性、论断保留、篇章模式审计等通用契约仍由 SKILL.md 的 C0–C6 负责。

## 0. 学术写作的「白名单」（**不要动**）

学术写作里有些特征是**文体要求**，不是 AI 痕迹。本技能会主动保护它们：

| 特征 | 例子 | 为什么不改 |
|---|---|---|
| 被动语态 | "数据通过问卷获取"、"样本被随机分组" | 实验方法段的写法惯例 |
| 名词化结构 | "……的显著提升"、"对……的影响" | 学术写作的精确表达 |
| 长定语 | "2023 年 8 月在川渝地区开展的、以大学生为对象的、基于选择实验的问卷调查" | 信息密度高，不算堆砌 |
| 第一人称复数 | "本研究"、"我们发现"、"本文提出" | 中文社科论文标准用法 |
| 引用句式 | "李聪（2021）指出……"、"已有研究表明……" | 必须保留，不能改写 |
| 公式、统计符号、文献编号 | *p* < 0.05；[1]；（Smith, 2020） | **锁定 span，绝对不修改** |

修改这些会破坏学术规范。判断不准时，宁可保留。

## 1. 中文学术 AI 味：六大典型病灶

按出现频率和暴露风险排序。修改时按这个顺序查：

### 病灶 A · 套话开头 / 套话过渡 / 套话收尾

学术 AI 文本最常见的三种骨架：

**开头空话**（删 / 换成具体场景）：
- "随着……的发展，……日益重要"
- "在……背景下，……成为研究热点"
- "近年来，……引起了广泛关注"
- "众所周知，……" / "不言而喻，……"
- "鉴于此" / "有鉴于此" / "基于此"（承接选题的"鉴于此，本文延续……"除外，见 §10-B）

**过渡连接**：
- "综上所述" / "概括而言" / "由此可见"——直接砍，这些是套话（"总而言之"是作者白名单，见 §10-A；"综上所述"仅在真正总结时合法，见 §2）
- "基于以上分析" / "通过以上讨论"——直接砍
- "首先……其次……再次……最后……"——见下面"病灶 E-学术分点写法"，按"是否真有并列要点"判断

**抒情收尾**（直接删，最后一段以事实/结论收尾）：
- "为……提供了新的思路" / "对……具有重要的参考价值"
- "未来值得进一步深入研究" / "有待后续研究进一步验证"（**空泛、无具体局限对象的抒情收尾**）
- "这正是……的意义所在" / "为……贡献了力量"

**Layer 7 合规例外**（有具体局限对象时保留，不算抒情收尾）：
- "这一发现有待跨地区样本验证" / "样本限制使……需谨慎对待" — 见 `references/layers/layer-7-academic-injection.md` §7.3

### 病灶 B · 价值判断词饱和

学术 AI 论文里 `重要 / 关键 / 显著 / 核心 / 突出 / 巨大 / 深远 / 不可忽视` 出现密度高，且往往没有证据。

**改写原则**：把"重要 / 关键"换成具体的证据或机理；"显著"只在统计学意义上保留，其他场合换成"明显"或具体描述。

> 原句：本研究对推动低碳消费具有重要意义。
> 改写：本研究为碳标签信息披露的政策设计提供了 692 名大学生的偏好证据。

> 原句：发挥了关键作用 / 起到重要作用
> 改写：写出实际做了什么（量化效果 / 具体行为 / 因果路径）

### 病灶 C · 抽象主语代替施动者

中文 AI 喜欢用抽象概念做事，避免交代到底是谁/什么做了什么：

**坏主语**：时代 / 科技 / 行业 / 社会 / 现实 / 未来 / 趋势 / 发展 + 动词

> 原句：随着时代的发展，消费观念正在发生深刻变化。
> 改写：受访的 692 名大学生里，73% 表示愿意为低碳标签外卖多付 1.65 美元。

**注意**：在学术论文的理论综述或背景段落，抽象主语有时是合法的（"已有研究指出……"）。判断依据是后面跟的具体细节能不能落地——能落地的，保留抽象主语；落不了地的，换成具体人 / 数据 / 场景。

### 病灶 D · "进行 + 名词 / 做出 + 名词 / 实现 + 名词" 类名词化动词

学术 AI 把直接动词藏进"动词 + 抽象名词"组合里。

| AI 写法 | 改写 |
|---|---|
| 进行优化 / 进行调整 | 优化 / 调整 |
| 做出选择 / 做出判断 | 选择 / 判断 |
| 实现增长 / 实现突破 | 增长 / 突破（直接用） |
| 采取措施 / 加以改进 | 写具体做了什么 |
| 起到作用 / 发挥作用 | 起作用 / 直接说结果 |
| 给予支持 / 提供保障 | 支持 / 保障 |

**例外**：方法论部分的"进行分析"、"进行检验"、"进行回归"是规范用语，不要机械去名词化。

### 病灶 E · 排比三件套

中文 AI 排比出现密度很高，因为训练数据里的政府工作报告 / 政策文件本身就爱排比：

> 原句：理论意义、实践意义、方法论意义，三者兼而有之。
> 改写：保留最有信息量的一句；如果三句意思不同，分三段说；如果只是同义重复，砍到一句。

> 原句：既是……，也是……，更是……
> 改写：保留最具体的一句。

学术段落里如果一定要列举，**用编号或表格**，而不是排比。

### 病灶 E-补充 · 学术分点写法（"首先/其次"该不该用）

`首先……其次……再次……最后……` 不是绝对要砍，要看**结构是否真有并列要点**。

**保留（合法使用）**：

学术写作里有真正的并列要点需要分点时，"首先/其次/最后" 是标准用法。判断标准：**后面跟的是 3 个或以上真正独立、并列、不合并的论点或发现**，且每个都有具体内容承上。

合法用例（摘要 / 结论 / 政策含义里常见）：
> 首先，相较高碳足迹外卖，大学生对低碳足迹外卖存在显著正向偏好；其次，受访者同样偏好环保包装；最后，男性、具有积极环保态度的、以及环境知识水平较高的大学生更倾向于选择低碳足迹外卖。

合法用例（多数据集 / 多方法 / 多维度汇报时）：
> 首先，本文使用 2018–2023 年上市公司年报数据进行实证检验；其次，本文通过案例访谈补充量化结果的解释；最后，本文在稳健性检验中变换了核心变量度量方式。

**砍掉（非法使用）**：

- 拿"首先/其次"做**文章骨架**而非**并列要点**：
  > ~~首先，本文将探讨低碳偏好的现状；其次，本文将分析碳标签的影响；最后，本文将提出政策建议。~~
  > 改成直接进研究内容。

- 只有 1–2 个发现但硬上"首先/其次/最后"：
  > ~~首先，受访者偏好低碳标签；其次，受访者偏好环保包装；最后，受访者倾向选择。~~（第三点只是前两点重述）
  > 砍到 2 句，删掉"首先/其次"和最后重述。

- 在不需要分点的段落里堆"首先/其次"：
  > ~~首先，数据表明……其次，回归结果显示……此外，稳健性检验进一步证实……~~（"其次"和"此外"重复）
  > 改成正常的叙事顺序，去掉这类过渡词。

**判断要点**：问两个问题——
1. 后面真的跟 3 个或以上**独立**论点/发现吗？是 → 保留"首先/其次"；否 → 砍
2. "其次"和"此外/同时/再者"在同一段落重复出现吗？是 → 砍

学术段落里**真正需要分点**时：可以用编号（"（1）……（2）……（3）……"）、加粗小标题、或带项目符号。也可以用"首先/其次/最后"，但前提是每个分点都有实质内容。

### 病灶 F · 假客观 / 假中立 / 元评论

学术 AI 的"假客观"特征：避免人称、堆"已有研究表明"。

**元评论句**（直接删，不要预告）：
- "本研究试图探讨……" → "本研究探讨……"
- "本文将分析……" → "本文分析……"
- "下面我们来看……" / "接下来我们将……"

**假中立堆砌**（替换为具体引用）：
- "诸多研究表明" / "大量研究证实" / "学界普遍认为"
  → 替换为 1–2 个具体研究："李聪（2021）发现……；Akiyama Sayuri（2019）以……验证了……"

## 2. 学术特定句式的合法用法（白名单补充）

学术写作的以下结构**不要改**：

| 结构 | 例子 | 何时合法 |
|---|---|---|
| "本研究 / 本文 + 发现 / 提出 / 旨在" | "本文旨在探讨……" | 摘要、研究目的段 |
| "基于……，本研究 + 动词" | "基于选择实验，本文检验了……" | 研究设计段 |
| "上述 + 名词" | "上述结果表明" | 结果/讨论段 |
| "如……所示" / "如表 X 所示" | "如表 3 所示，……" | 结果描述 |
| "由此可见" | "由此可见，碳标签显著正向影响偏好" | 结果收尾（**只在**有逻辑承上时使用，不能作为空话开头） |
| "综上所述" | "综上所述，碳标签信息披露能引导大学生选择低碳外卖" | 全文结论（**仅在**确实做了总结时使用，不能填充字数） |

判断标准：是不是真的有内容承上、承下。"综上所述"在最后一段且确实在总结时是合法的；在中间任何位置出现都是空话。

## 3. 中文学术特有的句式冗余

修改时主动检查：

**长串"的"字结构**（拆）：
> 原句：本研究的目的是为了探讨碳标签信息披露对于大学生消费偏好与支付意愿的影响及其作用机制。
> 改写：本研究考察碳标签信息披露对大学生消费偏好与支付意愿的影响及其作用机制。

**多重定语叠加**（保留信息密度高的；如果叠加的修饰语没有信息差异，砍）：
> 原句：2023 年 8 月在川渝地区面向 692 名大学生开展的基于离散选择实验的、关于碳标签信息披露对消费偏好影响的、问卷调查
> 改写：2023 年 8 月，川渝地区 692 名大学生接受了一次离散选择实验问卷调查

**"对……进行/开展/实施" 句式**（直接动宾）：
> 原句：对碳标签偏好进行分析
> 改写：分析碳标签偏好

## 4. 段落节奏与字数

中文学术论文的本地风格修复，重点不在字数，而在：

1. **同一段内句长变化**：避免 5 个连续句子都是 25–30 字
2. **每段一个核心句**：其余句子围绕它展开，不要每句都在抢结论位
3. **段间过渡用承接而非预告**：上一段的结论 + 下一段的问题，不要用"首先/其次"搭骨架
4. **结论段是事实而不是抒情**：最后一段以数据 / 推断 / 局限收尾，不以"为……贡献力量"收尾

## 5. 修改前后的对照清单

修改完成后，按这个清单过一遍（每千字检查一次）：

- [ ] 段首没有"在……背景下""随着……的发展""近年来"
- [ ] 没有"鉴于此 / 有鉴于此 / 基于此"空过渡
- [ ] 没有"为……提供了新的思路""具有重要意义""具有参考价值"
- [ ] 没有"未来值得进一步深入研究""有待后续研究进一步验证"（**空泛抒情收尾**；Layer 7 合规的"这一发现有待…验证"除外，见 §9）
- [ ] 没有"进行 + 抽象名词"组合（除非方法论段）
- [ ] 没有"实现 / 做出 / 加以 / 给予" + 抽象名词
- [ ] 没有连续三个排比短句
- [ ] 没有"诸多研究表明 / 大量研究证实 / 学界普遍认为"（替换为具体引用）
- [ ] 没有元评论（"本研究试图探讨""下面我们来看"）
- [ ] 最后一段以事实/数据/推断收尾，不以抒情收尾

## 6. 风险红线（**绝对不改**）

学术润色必须严守的事实红线：

- 数字、*p* 值、统计量、样本量、调查日期、地点 **一字不动**
- 参考文献条目 **不动**
- 引文（"……"内）**逐字不动**
- 专有名词、人名、机构名、项目编号 **不动**
- 已发表的方法名（如 discrete choice experiment、discrete choice model）**不动**
- 不删减、合并、修改任何论断（contract C1）

不确定时，保留原文。

## 7. 与英文版的对应（双语对照用）

| 英文 AI 味 | 中文对应 | 处理 |
|---|---|---|
| "In recent years, … has attracted increasing attention." | "近年来，……日益受到关注" | 砍掉，直接进背景 |
| "It is worth noting that …" | "值得注意的是……" | 砍（"需要注意的是 / 值得注意的是"作常规学术过渡时是作者白名单，见 §10-A；仅空话填充才处理） |
| "Paving the way for a new paradigm" | "为……开辟了新的路径" | 砍 |
| "Significantly outperforms"（无量化） | "显著优于"（无具体数字） | 若原文/表格已有数字则 surface；否则 soften，不发明 |
| "To the best of our knowledge" | "据我们所知" | 在中文学术里基本不用，可砍 |
| "Delve into" / "leverage" | "深入探讨" / "充分利用" | 砍或换具体动词 |
| "Groundbreaking" / "novel" | "开创性的" / "全新的" | 砍，价值判断词 |
| "First… Second… Third…" | "首先……其次……再次……最后……" | 砍或换句式 |
| "It can be seen from the above" | "综上所述" | 仅在真正总结时使用 |

## 8. 学术写作的"好中文"特征（写时的目标）

1. **句子有重有轻**：长句给条件/数据，短句给结论/判断
2. **每段有具体动作**：动词为主，避免"进行 / 给予"做唯一动词
3. **避免重复结论词**：同一篇文章里"显著""重要""核心"每个词不超过 2 次
4. **数字密度适中**：每段至少有 1 个具体数字或具体场景（**须来自原文**，Layer 4 不得发明）
5. **学术语气 vs 公文语气**：学术论文允许有判断、有保留（"本研究尚不能……"、"这一发现有待……"），不要写成政府报告

## 9. 与英文润色的差异

| 维度 | 英文 | 中文 |
|---|---|---|
| 缩写 | 不能用 "etc." 等模糊词 | 可以用"等" |
| 标点 | 严格空格 | 中文标点不空格 |
| 引号 | "double quotes" | 「」或 ""（按期刊规范） |
| 数字 | 英文千分位逗号 | 中文千分位空格或全角逗号 |
| 段落长度 | 学术英文偏长 | 中文学术更密集，建议每段不超过 200 字 |
| 主语 | "we" 学术常用 | 中文学术用"本研究""本文"，少用"我们" |

## 10. 别乱改清单（do-not-flag 白名单 · 作者领域校准）

> **优先级**：本节优先于病灶 A–F（§1）、§2 白名单补充与 §7 中英对照表的处理规则。
> 命中本清单的表达出现在**作者原稿**里时不是 AI 味，不得按套话清理或改写；
> 只有同一表达被当作空话**填充**（无承上、无内容）时，才回到 §1 / §7 的处理路径。
> 来源：作者（中文社科 / 经济学写作惯例）领域校准，2026-09。已署名提炼来源：[余泳泽、胡鹏和朱子政（2025）《耐心资本与企业颠覆性创新——基于企业机构投资者视角》，《中国工业经济》2025(10)：59-77](https://xueshu.baidu.com/s?wd=耐心资本与企业颠覆性创新)、[张大永、陈映彤和姬强（2023）《气候风险与外商直接投资：基于城市层面的实证研究》，《财贸研究》2023，34(12)：1-13](https://xueshu.baidu.com/s?wd=气候风险与外商直接投资)；第 3 批（C 组）提炼自第 1 篇的文献综述与概念界定段。

### A. 高频表达白名单（原样保留）

- 本文可能的贡献主要体现在以下三个方面
- 总而言之
- 考虑到数据的可得性
- 核心解释变量（固定术语，"核心"不是价值判断）
- 需要注意的是
- 进一步，本文还检验了……
- 为确保研究结论的可靠性，本文进行了以下稳健性测试（"进行了"在此是规范用语，不是病灶 D）

### B. 段落骨架惯例（结构就是领域标准写法，别当套话清理）

**结论部分**：
